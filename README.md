# ODTS website

This branch contains the Jekyll website published at `odts.nijida.de`.
Human-readable installation material, examples, and project documentation remain on the `main` branch. Website pages summarize and link to that material. The authoritative current behavior is always defined by `Nijida-Studio/ODTS-Specification`; ODTS-Home may describe an earlier version or contain documentation differences.

During the initial design phase this site uses
`Nijida-Studio/nijida-theme@themetest`. At the first official launch it will
switch to `Nijida-Studio/nijida-theme@main` together with the other Nijida
sites.
